Bolzduell Countdown

Runter auf exakt null. Drei Schüsse pro Runde. Wer überwirft, verliert die Runde.

Prototyp-Stand: Punkte werden per Fingertipp aufs Tor oder per Schnelltaste eingegeben. Eine erste Ballerkennung gibt es als Testfunktion (Kamerabild im Spiel). Sie ist ungeprüft und fragt jeden Treffer nach.

Einstellungen

Regeln: 3 Schüsse pro Runde, Treffer werden abgezogen, Ziel ist exakt 0. Überwerfen = Bust, Punktestand springt auf den Rundenbeginn zurück. Double-Out ist für eine spätere Version vorgesehen.
